# Honmaru AI iOS 1.2.0

Based on main after 1.1.0/build 47 (`d019f3c`), including the workspace
isolation changes from #124 and agent avatars from #125.

## UI corrections

- Japanese chat shortcuts wrapped into columns of one or two characters on
  iPhone SE (375 pt). They now use a vertical layout when a horizontal row
  cannot fit their labels, including at accessibility text sizes.
- At accessibility text sizes, Profile's AI assistant description and status
  now stack vertically instead of squeezing the description between an icon
  and badge.
- Welcome text has separation from the sign-in actions; the existing-account
  button has padding and centered multiline text at larger text sizes.

## Account deletion found during live verification

The disposable-account UI test signed in and restored its session successfully,
but its deletion returned HTTP 500. A scoped production log identified
`D1_ERROR: LIKE or GLOB pattern too complex`. Account deletion constructed DM
LIKE patterns from a login, exceeding D1's pattern limit for long email logins
and treating underscores as wildcards. DM participants are now compared
literally with substrings, for both messages and file cleanup. All nine
account-deletion tests pass, including long identifiers, wildcard characters,
both participant positions, and preservation of other conversations/files.
